Pagine HTML (HTM)

HTM mostra pagine HTML nel pannello: testi formattati, guide come questa, moduli esterni (Google Forms), piccole interfacce che comandano gli altri pannelli. Questa stessa guida è un oggetto HTM.

Due modalità

Confronto fra le modalità di HTM
"iframe""flow"
Dove sta la paginaIn una finestra isolata dentro il pannelloDentro la dashboard
Script della paginaFunzionano, ma non vedono la piattaformaTolti: la logica va in un flow
Stile della piattaforma (Bootstrap, icone)NoSì
Pulsanti che aprono le finestre della piattaformaNoSì
Adatta aSiti e moduli esterni, pagine completeGuide, schede, interfacce collegate agli altri pannelli
Flow collegatiSì, per cambiare la pagina (Frame/Navigate)Sì, per tutta la logica

Senza "mode" una pagina con file si apre in iframe. Per la modalità flow scrivi sempre "mode": "flow".

La vecchia modalità "inject" non esiste più: se la trovi in una spec, funziona come "flow".

Template "HTML — Pagina esterna (iframe)" base

{
  "mode": "iframe",
  "src": "https://docs.google.com/forms/d/e/XXXXX/viewform?embedded=true",
  "title": "Questionario"
}
  • src: l'indirizzo della pagina. Se invece scegli un file nel modello, src non serve.
  • title: nome della pagina letto dai lettori di schermo.
  • sandbox: permessi della finestra isolata; lascialo fuori, viene scelto da solo.

Molti siti vietano di essere mostrati dentro altre pagine: in quel caso il pannello resta bianco e non c'è rimedio. Google Forms, YouTube (indirizzo /embed/), Google Maps (indirizzo "incorpora") e Wikipedia lo permettono.

Pagina scelta da un flow. Senza src e senza file, cioè { "mode": "iframe", "title": "Pagina" } con il modello «Nessun file», il pannello mostra "Nessuna pagina" finché un flow collegato non ne carica una con il nodo HTM/Frame/Navigate, per esempio l'indirizzo ricevuto da un altro pannello con l'App Bus. Il pulsante apre in una nuova scheda la pagina mostrata.

Template "HTML — Scheletro + Flow (nodi DOM)" base

Il modo consigliato per le pagine scritte da te:

  1. scrivi la pagina in un file .html (o .txt, vedi sotto) e caricala;
  2. nel modello scegli il file e metti la spec:
{ "mode": "flow", "title": "Titolo della pagina" }

In alternativa al file si può scrivere l'HTML direttamente nella spec, nel campo srcdoc: quella strada è riservata all'amministratore. Con un file caricato non ci sono limiti di ruolo.

I file .html si caricano solo se l'amministratore ha protetto la cartella dei dati. In alternativa rinomina la pagina in .txt: con "mode": "flow" funziona allo stesso modo.

Più pagine collegate allo stesso oggetto compaiono nel menu a sinistra del pannello.

Scrivere la pagina (modalità flow)

  • Codifica UTF-8; metti <meta charset="utf-8"> come prima riga, utile se la pagina si apre anche da sola.
  • Basta il contenuto: <style> e poi il markup. Se scrivi una pagina completa, si usa solo il <body>.
  • Vengono tolti: <script>, <iframe>, <link>, <meta>, gli attributi onclick, onload… e i link javascript:.
  • Restano: <style>, classi Bootstrap, icone <i class="bi bi-…">, immagini, link, <details> per le parti apribili.
  • Racchiudi lo stile sotto una classe tua (es. .mia-guida h3 { … }), altrimenti cambia anche il resto della dashboard.
  • Dai alla pagina uno sfondo (background: var(--bs-body-bg)): il pannello di suo è trasparente.
  • Lascia circa 36 px liberi in alto: l'intestazione del pannello si sovrappone al contenuto.

Renderla interattiva

Dai un id agli elementi da usare e collega all'oggetto un flow con i nodi HTM/DOM/*:

Nodi principali HTM/DOM
NodoA cosa serve
DOM QueryTrova un elemento della pagina (es. #risultato).
On EventReagisce a clic, invio di un modulo, tasti.
Get Value / Set ValueLegge o scrive il valore di un campo.
Set TextScrive un testo, anche in Markdown.
Set Class / Set AttrAggiunge o toglie classi e attributi (es. evidenziare un passo).
Set OptionsRiempie un menu a tendina.
Get Image / Set ImageLegge un'immagine scelta dall'utente o ne mostra una.
Chat ViewRiquadro di dialogo a fumetti (es. con un modello di intelligenza artificiale).
Button RowFila di pulsanti creata da un elenco (scelte, schede, collegamenti).
Set HTMLScrive un pezzo di HTML ripulito, per esempio un articolo di Wikipedia letto con Web/Wikipedia/Article.
On SelectionReagisce al testo selezionato da chi legge.
Container, Label, Button, InputCreano elementi nuovi, se la pagina è vuota.

Con i nodi App Bus la pagina può comandare gli altri pannelli: un pulsante "mostra la facciata" che sposta la camera del 3D accanto.

Template HySpace avanzato

Tre template pronti costruiscono la pagina da soli con un nodo dedicato, senza file:

  • Scheda esercitazione HySpace (flow): mostra la scheda della stanza in cui ci si trova in un pannello HySpace.
  • Ricerca e musei HySpace (flow): cerca le esercitazioni e genera musei tematici.
  • Archivio esercitazioni HySpace (flow): archivio per anno con scheda e modello 3D.

Lo schema dei flow da collegare è nella spiegazione di ciascun template, nella finestra della spec.

Problemi comuni

  • Lettere accentate sbagliate (Ã¨) e pulsanti che non aprono nulla. La pagina è in iframe: manca "mode": "flow".
  • Pagina trasparente, si vede lo sfondo del pannello. Dai uno sfondo al contenitore principale della pagina.
  • Il titolo è coperto. Lascia spazio in alto (36 px).
  • Un pulsante onclick non fa nulla. Gli attributi on… vengono tolti: usa un flow con On Event.
  • "Salvataggio rifiutato" sulla spec. Hai messo HTML in srcdoc senza essere amministratore: usa un file.
