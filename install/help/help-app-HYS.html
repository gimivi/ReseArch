HySpace (HYS) avanzato

HySpace è un museo virtuale in prima persona delle esercitazioni degli allievi: ogni stanza espone un'esercitazione con le sue immagini alle pareti, e le porte portano alle esercitazioni collegate. È l'erede del museo VRML 2005–2013.

Come è fatto

Forma e contenuto in HySpace
Da dove vieneCosa decide
Forma delle stanzeI modelli 3D collegati all'oggetto HYS (Room_01 … Room_06)Pareti, pavimenti, scale e dove appendere i pannelli
ContenutoL'archivio delle esercitazioni di HySpaceQuale esercitazione è esposta e dove portano le porte

Attorno alla stanza in cui sei ci sono sei stanze vicine: davanti, dietro, a sinistra e a destra le esercitazioni collegate; sopra e sotto l'esercitazione successiva e precedente dello stesso allievo. Dove non c'è un'esercitazione, la porta resta chiusa.

Muoversi

  • Menu del pannello → Entra in navigazione: il mouse guida lo sguardo, W A S D per camminare.
  • Esc restituisce il mouse.
  • Su tablet e telefono: menu → Touch: levetta ↔ tocca per andare sceglie fra una levetta a schermo e il tocco sul punto da raggiungere.
  • Con un visore: Entra in VR (visore). C'è anche Schermo intero.
  • Dal menu: Torna all'ingresso, salita e discesa, musica, ombre, Ricarica contenuti.

Template "Stanza con pannelli espositivi" avanzato

È la spec di ciascun modello-stanza (un file glTF/OBJ): dice dove appendere le immagini sulle sue pareti.

{
  "expo": {
    "zones": [
      { "x": 4, "z": 0, "rotDeg": 270, "width": 3 },
      { "x": 4, "z": 2, "rotDeg": 270, "width": 3 },
      … in tutto 8 zone …
    ],
    "panelsY": 1.65,
    "panelHeight": 3.0,
    "panelMargin": 0.20
  },
  "hys": { "start": true, "door": { "width": 3, "height": 3, "distance": 5 } }
}
Campi della spec di una stanza
CampoEffetto
expo.zones8 zone di parete. x, z = posizione nella stanza (metri, come nel file 3D); rotDeg = orientamento in gradi attorno alla verticale; width = larghezza disponibile. Una zona vuota viene saltata.
expo.panelsYAltezza da terra del centro dei pannelli (predefinito 1,65 m).
expo.panelHeightAltezza dei pannelli (predefinito 3 m).
expo.panelMarginCornice attorno a ogni immagine (predefinito 0,20 m).
hys.startQuesta è la stanza d'ingresso. Senza, vale quella chiamata Room_01.
hys.doorMisure della porta chiusa (larghezza, altezza, distanza dal centro).

I valori del template sono un esempio (un quadrato ideale): vanno ricavati dalla geometria vera della stanza, misurando dove sono le pareti nel file 3D. transform qui non ha effetto: le stanze le dispone HySpace.

Pannelli collegati

A ogni ingresso in una stanza HySpace annuncia agli altri pannelli quale esercitazione si sta guardando. Con l'App HTM ci sono tre template pronti:

  • Scheda esercitazione: titolo, autore, testi e immagini della stanza corrente, accanto al museo.
  • Ricerca e musei: cerca le esercitazioni, porta il museo su una di esse o genera un museo tematico.
  • Archivio esercitazioni: elenco per anno, con scheda e modello 3D.

I flow dell'oggetto HYS possono anche impostare la musica di sottofondo (file .mp3 nelle cartelle del WP).

Problemi comuni

  • Porte tutte chiuse. L'archivio non ha risposto: menu → Ricarica contenuti.
  • Immagini fuori dalle pareti o storte. Le zone di expo non corrispondono alla geometria della stanza.
  • Ogni volta si riparte dall'ingresso. È normale: la posizione non viene salvata.
