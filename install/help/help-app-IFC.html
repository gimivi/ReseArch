Modelli BIM (IFC)

IFC mostra modelli BIM (edifici con elementi, livelli e proprietà) nel formato veloce Fragments di That Open. Il modulo è ancora in sviluppo: leggi la sezione qui sotto prima di prepararci un'esercitazione.

Per mostrare oggi un edificio con più strumenti (sezioni, misure, luci), esportalo in glTF/GLB e usa l'App 3D (TJS).

Mouse

  • Tasto sinistro trascinato: ruota la vista. Tasto destro trascinato: sposta la vista. Rotella: avvicina/allontana.
  • Clic su un elemento: lo evidenzia e ne mostra le proprietà; clic nel vuoto: toglie la selezione.
  • Doppio clic su un elemento: la vista ruota attorno a quel punto. Con Sezione, Misura lunghezza o Misura area attivi il doppio clic serve a quello strumento e il clic non seleziona: ripremi il pulsante per spegnerlo.

Preparare il file

  1. Esporta il modello in IFC dal programma BIM (Revit, Archicad, BlenderBIM…).
  2. Carica l'.ifc in una sottocartella del WP: si apre così com'è.
  3. Per modelli grandi: aprilo una volta e premi Salva nel modello ▾ → Salva come .frag; il .frag viene salvato accanto e usato dalle aperture successive.

Modelli e spec

  • Un modello per file .ifc o .frag; tutti quelli collegati all'oggetto si caricano insieme (es. architettonico + strutturale + impianti).
  • Della spec IFC legge views (viste), measures (misure) e planes (piani di sezione) salvati, nel primo modello .ifc/.frag dell'oggetto. Si scrive dalla finestra Viste → Salva nel modello (livello autore); le altre chiavi della spec restano come sono. Template Modello BIM (Fragments): { }.
{
  "views": [
    { "name": "Ingresso", "position": { "x": 10, "y": 60, "z": 10 }, "target": { "x": 27, "y": 0, "z": 19 }, "plan": null },
    { "name": "Pianta 2", "position": { "x": 27, "y": 40, "z": 19 }, "target": { "x": 27, "y": 0, "z": 19 }, "plan": "02 - Floor" }
  ]
}
  • position e target in metri; plan = nome della pianta (come nella finestra Piante) oppure null per la vista 3D.
  • measures si scrive col pulsante Salva nel modello ▾ → Salva le misure: { "lengths": [ { "start": [x,y,z], "end": [x,y,z] } ], "areas": [ { "points": [[x,y,z], …] } ], "angles": [ { "start": […], "vertex": […], "end": […] } ], "volumes": [ { "guids": [ "GlobalId", … ] } ] }, coordinate in metri; i volumi ricordano gli elementi sommati.
  • planes si scrive col pulsante Salva nel modello ▾ → Salva le sezioni: [ { "point": [x,y,z], "normal": [x,y,z] } ]; resta visibile la parte verso cui punta normal.

Problemi comuni

  • Il modello è sparito dalla vista. Premi Inquadra tutto.
  • Il modello compare a pezzi mentre giri la vista. È normale: i dettagli si caricano quando la camera si ferma.
