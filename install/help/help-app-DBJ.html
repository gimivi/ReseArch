Tabelle JSON (DBJ)

DBJ mostra una tabella i cui dati stanno dentro la spec del modello, senza file e senza database. È adatta a elenchi piccoli e stabili (una legenda, un indice di tavole, un glossario) che vuoi collegare ad altri pannelli.

Il template "JSON Tabulator" base

Nel modello scegli Nessun file (dati dal flow): i dati li scrivi nella spec, che qui è obbligatoria.

{
  "data": {
    "records": [
      { "codice": "T01", "titolo": "Pianta piano terra", "scala": 100 },
      { "codice": "T02", "titolo": "Prospetto nord",     "scala": 50 }
    ]
  },
  "view": {
    "columns": [
      { "field": "codice", "caption": "Tav.",   "width": 80, "mode": "r" },
      { "field": "titolo", "caption": "Titolo", "mode": "r" },
      { "field": "scala",  "caption": "Scala 1:", "width": 90, "mode": "r" }
    ]
  },
  "busKey": "codice"
}
Campi della spec DBJ
CampoEffetto
data.recordsObbligatorio. Le righe: un oggetto { } per riga. Senza, il pannello dà errore.
view.columnsFacoltativo. Colonne da mostrare, in ordine. Se manca, si usano le chiavi della prima riga.
  fieldLa chiave del record da mostrare.
  captionTitolo della colonna.
  widthLarghezza in pixel.
  mode"r" sola lettura; "rw" (predefinito) permette di scrivere nella cella ma non salva.
busKeyFacoltativo. Il campo che identifica la riga negli scambi con gli altri pannelli (vedi sotto).

Per cambiare i dati si modifica la spec dalla modale Modelli. Se servono modifiche frequenti o da più persone, usa MYS (database) o GSH (foglio Google).

Collegarla ad altri pannelli

Con busKey impostato, il clic su una riga annuncia agli altri pannelli della dashboard "è stato scelto codice = T02". Un flow o un'App che ascolta quel campo può reagire: aprire la tavola, centrare la mappa, evidenziare un oggetto nel 3D.

  • Senza busKey il clic non viene annunciato, ma un flow dell'oggetto riceve comunque la riga scelta.
  • La tabella si ricarica da sola quando un altro pannello o un flow annuncia che i dati sono cambiati.

Problemi comuni

  • Errore all'apertura. Manca data.records o non è un elenco tra parentesi quadre.
  • La spec non si salva. JSON non valido: controlla virgole e virgolette con Valida.
  • Il clic non muove gli altri pannelli. Manca busKey, oppure il campo indicato non esiste in tutte le righe.
