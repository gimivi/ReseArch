Tabelle da file CSV

L'App CSV mostra un file .csv come tabella ordinabile. È il modo più semplice per pubblicare dati esportati da Excel o da un altro programma: carichi il file e lo colleghi, senza scrivere nulla.

Il file

  • La prima riga contiene i nomi delle colonne.
  • Il separatore può essere ; (Excel in italiano) o ,: viene riconosciuto da solo.
  • I testi con separatori o a capo vanno tra virgolette doppie, come fa Excel.
  • Salva in UTF-8 (in Excel: CSV UTF-8 (delimitato da virgole)), altrimenti le lettere accentate si rovinano.

Il template "CSV Tabulator" base

La spec è facoltativa. Con { } la tabella mostra tutte le colonne del file, con i loro nomi. La usi solo per scegliere quali colonne mostrare, in che ordine e con che titolo.

{
  "view": {
    "columns": [
      { "field": "nome",   "caption": "Nome",   "width": 200, "mode": "r" },
      { "field": "valore", "caption": "Valore" }
    ]
  }
}
Campi di una colonna
CampoEffetto
fieldNome della colonna come scritto nella prima riga del file (maiuscole comprese).
captionTitolo da mostrare al posto del nome originale.
widthLarghezza in pixel.
mode"r" sola lettura. "rw" (predefinito) permette di scrivere nella cella, ma non salva nulla: alla riapertura torna il file.

Consiglio: metti "mode": "r" su tutte le colonne, così nessuno crede di aver modificato i dati.

Problemi comuni

  • Tutto in una colonna sola. Il separatore non è né ; né , (per esempio è una tabulazione): riesporta il file.
  • Colonna vuota. Il field non corrisponde esattamente all'intestazione del file.
  • Lettere accentate sbagliate. Il file non è in UTF-8: riesportalo come "CSV UTF-8".
