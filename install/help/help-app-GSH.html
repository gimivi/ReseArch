Fogli Google (GSH)

GSH mostra un foglio di Google Sheets come tabella con ricerca. I dati si modificano in Google, da chiunque abbia accesso al foglio; la piattaforma li legge e può aggiornarli da sola a intervalli regolari.

Condividere il foglio

  1. In Google Sheets: Condividi → Accesso generale → Chiunque abbia il link → Visualizzatore.
  2. Copia dall'indirizzo del foglio l'ID, la parte tra /d/ e /edit:
    https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMd…upms/edit#gid=0
  3. Se ti serve una scheda diversa dalla prima, aprila e copia il numero dopo gid=.

Chiunque abbia il link può leggere il foglio: non metterci dati personali o riservati.

Il template "Google Sheet" base

Modello Nessun file (dati dal flow); il foglio si indica nella spec.

{
  "spreadsheetId": "1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms",
  "gid": "0",
  "hasHeaders": true,
  "limit": 1000,
  "pageSize": 25,
  "autoRefresh": 0,
  "searchFields": ["Nome", "Città"],
  "columns": [
    { "field": "Nome", "title": "Nome teatro", "width": 200 },
    { "field": "Data", "title": "Data", "formatter": "date" },
    { "field": "Foto", "title": "Foto", "formatter": "image" }
  ],
  "busKey": "id",
  "sheetName": "Teatri"
}
Campi della spec GSH
CampoPredefinitoEffetto
spreadsheetId—Obbligatorio. L'ID copiato dall'indirizzo, senza altro.
gid"0"La scheda del foglio; 0 = la prima.
hasHeaderstrueLa prima riga contiene i nomi delle colonne. Con false le colonne si chiamano col_1, col_2…
limit1000Righe massime lette (al massimo 10000).
pageSize25Righe per pagina.
autoRefresh0Ogni quanti secondi rileggere il foglio; 0 = mai. Per un foglio aggiornato durante un incontro, 60 basta.
searchFieldstutteColonne in cui cerca la casella di ricerca.
columnstutteColonne da mostrare: field (nome dell'intestazione), title, width, formatter.
busKey—Campo scambiato con gli altri pannelli.
sheetNamenome del modelloEtichetta nel menu a sinistra quando l'oggetto ha più fogli.

Formati di colonna (formatter)

  • "date", "datetime", "money", "boolean", "badge" (con "colors"): come in MYS.
  • "link": la cella diventa un collegamento che si apre in una nuova scheda.
  • "image": la cella contiene l'indirizzo di un'immagine, che viene mostrata.

Altri pannelli

Con busKey il clic su una riga viene annunciato agli altri pannelli, e una riga si evidenzia quando un altro pannello sceglie lo stesso elemento. Un flow può anche chiedere di rileggere il foglio.

Problemi comuni

  • Errore 403 / accesso negato. Il foglio non è condiviso con "Chiunque abbia il link".
  • ID non valido. Hai copiato anche /edit o altri pezzi dell'indirizzo: serve solo l'ID.
  • Vedo la scheda sbagliata. Controlla gid.
  • Le modifiche in Google non compaiono. Premi Ricarica nel pannello o imposta autoRefresh.
  • Non posso scrivere dalla tabella. È normale: GSH è in sola lettura.
