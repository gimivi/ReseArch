Geometria interattiva (JSX)

JSX crea una tavola geometrica (piano cartesiano) su cui disegnare punti, rette, curve, coniche e costruzioni che si possono trascinare. È pensata per la didattica della geometria e della rappresentazione.

Come funziona

Parti di un oggetto JSX
ParteCosa contiene
Spec del modelloCom'è la tavola: estensione, assi, griglia, proporzioni, più dei parametri per il disegno.
Flow dell'oggettoIl disegno vero e proprio, scritto in un nodo JSX/Script.

Il modello non ha bisogno di file: scegli Nessun file (dati dal flow). Con più modelli collegati, il menu a sinistra passa da una tavola all'altra, ognuna con la sua spec.

Prima del 28 settembre 2026 il disegno era un file .mjs caricato come modello. Quel file oggi non viene più eseguito: per riusarlo copia il contenuto della sua funzione setup in un nodo JSX/Script.

I template

{
  "boundingbox": [-6, 6, 6, -6],
  "axis": true,
  "grid": false,
  "keepaspectratio": false,
  "showNavigation": true,
  "boardOptions": {},
  "params": {}
}
Campi della spec JSX
CampoEffetto
boundingboxLa parte di piano visibile all'apertura. Ordine insolito: [x minima, y massima, x massima, y minima], cioè angolo in alto a sinistra e poi in basso a destra.
axisAssi cartesiani con le tacche.
gridGriglia di sfondo.
keepaspectratioStessa scala sui due assi: un cerchio resta un cerchio anche se il pannello è stretto.
showNavigationPulsantini di zoom e spostamento in basso a destra.
boardOptionsOpzioni native di JSXGraph, per chi le conosce. Es. { "pan": { "enabled": false }, "zoom": { "enabled": false } } blocca la vista.
paramsValori liberi passati al disegno. Così lo stesso flow disegna figure diverse in modelli diversi.

TemplatePer cosa

Il disegno nel flow

  1. Crea un flow di tipo Oggetto e collegalo all'oggetto JSX (modali Flow e Collegamenti).
  2. Apri l'oggetto, premi Flow embedded e aggiungi un nodo JSX/Script.
  3. Scrivi il disegno. Il codice ha già a disposizione board (la tavola), JXG (la libreria) e params (dalla spec).
// circonferenza per tre punti trascinabili; il raggio dei punti viene dalla spec
const r = params.r ?? 3;
const A = board.create('point', [-r, 0], { name: 'A' });
const B = board.create('point', [0, r],  { name: 'B' });
const C = board.create('point', [r, 0],  { name: 'C' });
board.create('circumcircle', [A, B, C], { strokeColor: '#0066cc' });

Il nodo contiene codice: finché un amministratore non valida il flow, il disegno lo vedi solo tu. Gli altri utenti vedono la tavola vuota.

Dalla barra del pannello: Ripristina vista iniziale, mostra/nascondi assi e griglia, Esporta come SVG.

Problemi comuni

  • Tavola vuota. Il flow non è collegato, non è stato scelto all'apertura, oppure è ancora in attesa di validazione.
  • Vista capovolta o schiacciata. Controlla l'ordine dei quattro numeri di boundingbox.
  • Cerchi ovali. Metti "keepaspectratio": true.
  • Avevo un file .mjs che funzionava. Non viene più eseguito: sposta il suo codice in un nodo JSX/Script.
