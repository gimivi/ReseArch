Immagini gigapixel (OSD)

OSD mostra immagini molto grandi (rilievi fotografici, tavole, mosaici) caricando solo i pezzi che servono allo zoom corrente. Sopra l'immagine c'è un livello di disegno vettoriale per annotare, misurare e ridisegnare, e un pannello di filtri per leggere meglio i dettagli.

Preparare l'immagine

OSD non legge un .jpg o un .tif direttamente: l'immagine va prima tagliata in tasselli nel formato Zoomify. Il risultato è una cartella così:

Facciata_nord/
  ImageProperties.xml     ← il file da scegliere nel modello
  TileGroup0/
    0-0-0.jpg
    1-0-0.jpg  …
  TileGroup1/  …

Come ottenerla

  • libvips (gratuito, riga di comando): vips dzsave immagine.tif Facciata_nord --layout zoomify
  • Photoshop: File → Esporta → Zoomify.
  • Qualsiasi altro programma che esporti in formato Zoomify.

Caricarla

  1. In Caricamenti scegli la sottocartella del WP.
  2. Trascina l'intera cartella (non i singoli file): la struttura con i TileGroup deve restare uguale.

I file .xml si caricano solo se l'amministratore ha protetto la cartella dei dati (come per le pagine HTML).

Un'immagine gigapixel produce migliaia di tasselli: il caricamento può durare a lungo. Non chiudere la finestra finché non è finito.

Modello e spec

  1. In Modelli crea il modello e con Seleziona file… entra nella cartella dell'immagine e scegli ImageProperties.xml.
  2. Per la spec scegli il template Immagine gigapixel (Zoomify): OSD non legge la spec, quindi resta
{ }
  • Crea un oggetto con App OSD e collega il modello.
  • Un'immagine per oggetto. Se colleghi più modelli, OSD mostra solo il primo.
  • Il modello senza file (Nessun file (dati dal flow)) non va bene per OSD: serve sempre l'immagine.

Disegni e filtri

Disegni e filtri non stanno nella spec: si salvano come disegni legati al modello, dalla barra del pannello.

Strumenti del pannello OSD
GruppoCosa fa
Apri / SalvaApre un disegno salvato o salva quello corrente (con nome e versioni). Un disegno contiene livelli, forme, testi e filtri.
Linee, Poligoni, QuadrichePunti, linee, polilinee, curve, rettangoli, poligoni, archi, cerchi, ellissi.
AnnotazioniTesti su più righe con stili, simboli SVG, collegamenti e immagini.
TrasformazioniSeleziona, sposta, copia, ruota, scala, elimina, proprietà.
Annulla / RipetiFino a 30 passi.
Livelli, ImpostazioniLivelli con colore e tipo di linea; aggancio ai punti e tolleranze di selezione.
Filtri immagineLuminosità, contrasto, gamma, nitidezza, rilevamento bordi, scala di grigi, mappe di colore, soglia, shader personalizzati.

Prima di disegnare apri o crea un disegno: File → Lista disegni… → Nuovo (o Apri). Senza un disegno aperto, con almeno un livello attivo e visibile, gli strumenti non partono.

Navigazione: rotella = zoom, Spazio + trascinamento = spostamento. Il tasto destro chiude lo strumento in corso e torna alla navigazione; un altro clic destro ripete l'ultimo strumento.

Le coordinate dei disegni sono in pixel dell'immagine originale: una misura fatta allo zoom massimo o minimo dà lo stesso risultato.

I filtri si salvano insieme al disegno. Se non salvi un disegno, alla riapertura l'immagine torna senza filtri.

Problemi comuni

  • "OpenSeadragon richiede un'immagine". Il primo modello collegato non ha un file: scegli ImageProperties.xml.
  • Errore "IMAGE_PROPERTIES non trovato". Il file scelto non è un ImageProperties.xml Zoomify (per esempio è un'immagine o un file Deep Zoom .dzi).
  • Immagine sfocata o a quadretti grigi. Mancano dei tasselli: la cartella è stata caricata solo in parte o i TileGroup non sono accanto al file XML.
  • "Nessun disegno aperto". Apri o crea un disegno da File → Lista disegni….
  • "Layer attivo spento". Il livello su cui disegni è nascosto: riaccendilo in Livelli o scegline un altro.
  • Non riesco a spostare l'immagine. È attivo uno strumento di disegno: premi il tasto destro per tornare alla navigazione.
