Ontologie (OWL)

OWL disegna un'ontologia come grafo: classi, individui e proprietà diventano nodi e frecce che si possono spostare, filtrare e riordinare. Serve per mostrare e discutere vocabolari, tassonomie e modelli di dati (CIDOC-CRM, thesauri…).

I file .owl e .rdf si caricano solo se l'amministratore ha protetto la cartella dei dati. In alternativa rinomina il file in .txt e scrivi il formato nella spec: il contenuto non cambia.

Il template "OWL" base

{
  "format": "rdf-xml",
  "layout": "dagre",
  "filter": {
    "showClasses": true,
    "showIndividuals": true,
    "showProperties": true
  }
}
Campi della spec OWL
CampoEffetto
formatIl formato del file (tabella sopra). Se manca si deduce dall'estensione; con un .txt va sempre scritto.
layoutCome disporre il grafo all'apertura: "dagre" gerarchico, dall'alto in basso (tassonomie, predefinito) · "cose" a forze (grafi fitti di relazioni) · "circle" in cerchio (ontologie piccole) · "breadthfirst" a livelli.
filterQuali nodi mostrare. Con ontologie grandi, "showIndividuals": false lascia solo la tassonomia.

OWL usa solo il primo modello collegato all'oggetto.

Dalla barra: cambio di disposizione, mostra/nascondi classi e individui, Adatta vista, Mostra tutto per togliere le evidenziazioni, Esporta PNG. Cambiare disposizione dalla barra non modifica la spec.

Problemi comuni

  • "Errore parsing". Il format non corrisponde al contenuto del file (per esempio un RDF/XML letto come Turtle).
  • "Nessun elemento OWL trovato". Il file è RDF ma non dichiara classi, proprietà o individui OWL/RDFS.
  • Grafo illeggibile. Nascondi gli individui, prova "cose", oppure dividi l'ontologia in più file e più oggetti.
