Le finestre

  • Layer: fondo; per ogni layer accendi/spegni, inquadra, porta su o giù, opacità, confronto a tendina (trascina la linea per vedere sotto); legenda.
  • Proprietà: attributi dell'elemento selezionato, coordinate, lunghezza o area; con il Catasto acceso, un clic fuori dagli elementi mostra foglio e particella.
  • Cerca: layer, attributo e valore (uguale o contiene); clic su un risultato per selezionarlo; Mostra solo questi.
  • Colora per valore: un colore per ogni valore di un attributo, con legenda.
  • Viste: vista attuale con nome (centro, zoom, fondo, layer accesi); Salva nel modello per gli autori.

Il menu a sinistra e il menu ☰ a destra mostrano i comandi aggiunti dal flow dell'oggetto.

Disegnare

  1. Apri Disegno e scegli Disegna su: Nuovo disegno oppure un layer GeoJSON dell'oggetto.
  2. Scegli lo strumento: Punto, Linea o Area (doppio clic per finire), Modifica (trascina i vertici, Alt+clic ne toglie uno), Elimina (clic sull'elemento).
  3. Con Modifica, clic su un elemento per scriverne gli attributi (per esempio name, usato per le etichette).
  4. Salva come GeoJSON crea un nuovo file nella cartella del primo modello; su un layer dell'oggetto Salva il file riscrive il suo file. Serve il livello autore.
Un nuovo file non diventa da solo un layer: per vederlo ogni volta crea un modello con il template Cartografia — Layer vettoriale.

Problemi comuni

  • Il clic non seleziona: è acceso uno strumento di misura o di disegno; spegnilo.
  • Riga gialla nella finestra Layer: il file o il servizio non si è caricato; il testo dice perché.
  • Esporta PNG si ferma: un servizio acceso non lo permette (nessuno di quelli del catalogo attuale); spegnilo dalla finestra Layer.
